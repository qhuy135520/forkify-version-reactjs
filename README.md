# 🍽️ Forkify (ReactJS Version)


A modern ReactJS recreation of the Forkify recipe application from Jonas Schmedtmann's JavaScript course, featuring enhanced state management and a responsive design.

## 🚀 Features

- 🔍 Search over 1,000,000 recipes (Forkify API v2)
- ❤️ Bookmark favorite recipes with local storage
- 🍕 Custom recipe creation and upload
- ⚖️ Dynamic ingredient quantity adjustment
- 📱 Fully responsive UI (Mobile-first design)

## 🛠️ Tech Stack & Implementation

### React Fundamentals Mastered
- Functional components with hooks (`useState`, `useEffect`, `useContext`)
- Custom hooks for reusable logic
- React Router for SPA navigation
- Context API for global state management
- Error boundaries and error handling

### Advanced Patterns Implemented
- Component composition patterns
- Prop drilling solutions
- Performance optimization (React.memo, useCallback)
- Form management with controlled components
- React portal for modal implementation

### API & Data Handling
- Axios for API requests
- Asynchronous state management
- Data fetching patterns (loader states, error handling)
- Local storage synchronization
- Data transformation and normalization
